# 月饼营养核验库说明

月饼营养核验库需要在多方参与、事件顺序不稳定和服务重启的情况下保持记录一致。每条记录有所属方、状态和递增版本，所有状态变化写入事件表；请求键用于抵御重复提交，事务失败时整次写入回滚。

## 标签核验

营养表统一换算到每百克目标单位（能量 kJ、脂肪 g、钠 mg、糖 g），支持每份折算与 kcal↔kJ；缺失或单位异常的标签标记为 invalid，生成按 (label, kind) 去重的告警，且不得进入推荐。原料隐含的过敏原与标签申报比对，发现冲突时阻止发布并写入审计事件。规则按版本保存，推荐结果落库时记录规则版本与快照，历史订单仍按当时版本解释；顾客画像只在授权范围内参与计算，每个关注点只产生一个结论，提醒文案由结论派生，保证不互相矛盾。批次导入以批次号为幂等键，重复导入返回首次结果；使用文件库时重启后结果与审计记录一致。
